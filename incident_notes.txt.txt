Operation Fire – Incident Investigation Notes

Investigation Summary:
During this Blue Team lab simulation, suspicious endpoint and network activities were generated and investigated using Sysmon, Event Viewer, PowerShell, and Wireshark.

Observed Activities:
1. Suspicious PowerShell encoded command execution.
2. Unauthorized local user account creation.
3. Multiple process creation and termination events.
4. Active outbound network traffic observed in Wireshark.
5. TLS and TCP communications captured during traffic analysis.

Indicators of Compromise (IOCs):
- Encoded PowerShell execution attempt
- Creation of suspicious local accounts:
  • hacker_test
  • security_test
- High volume process telemetry events
- Multiple outbound encrypted traffic sessions

Investigation Tools Used:
- Sysmon
- Windows Event Viewer
- Wireshark
- PowerShell
- Kali Linux
- VirtualBox

Analysis Outcome:
No real malware infection was detected. All suspicious activities were safely simulated in a controlled cybersecurity lab environment for learning and monitoring purposes.

Skills Practiced:
- Endpoint monitoring
- Event log investigation
- IOC identification
- Network traffic analysis
- Security documentation
- Blue Team workflow fundamentals
